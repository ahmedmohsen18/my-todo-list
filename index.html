Sync across devices

Keep your iPhone and Mac showing the same lists, live. Your tasks are stored in a secret Gist on your own GitHub account — nothing new to sign up for.

  1. Open GitHub's token page (the gist permission is pre-ticked), scroll down, tap Generate token, and copy it.
  2. Paste it below and tap Enable sync.
  3. Do the same on your other device — reuse this token or generate a new one, either finds the same data automatically.

Enable it first on the device whose lists are most up to date — other devices adopt that data when they join. The token is saved only on this device.

✅ Sync is on. Changes upload automatically; devices refresh about every 20 seconds and whenever you reopen the app (pull down to refresh forces it too).

🗓 Subscribe in Apple Calendar

iPhone shows "Subscribe to calendar?" — tap Subscribe. Alarms then ring exactly on time, because Apple rings them locally.

Important: make new tasks arrive quickly
  1. iPhone Settings → Apps → Calendar → Calendar Accounts → Fetch New Data.
  2. Set the schedule to Every 15 minutes.
  3. Also tap the subscribed calendar there and make sure Remove Alerts is OFF — if it is on, iOS strips the reminder and nothing rings.

Then any task dated 20+ minutes ahead arrives in time and rings to the second. For something due sooner, use ⏰ on the task to add it to Calendar instantly.

Use Outlook instead of Apple Calendar?

Best way (keeps alarms exact):

  1. Settings → Apps → Calendar → Calendar Accounts → Add Account → Microsoft Exchange (use this for a work account; "Outlook.com" is only for personal ones).
  2. Enter the work address, tap Next → Sign In, and complete the Microsoft sign-in.
  3. Turn Calendars ON (Mail and Contacts are optional) → Save.
  4. Back in Settings → Apps → Calendar, set Default Calendar to the work calendar.

Every reminder added with ⏰ now lands in Outlook, syncs to laptop and web, and still rings exactly on time because iOS fires the alarm locally. Work meetings also show up alongside your tasks.
